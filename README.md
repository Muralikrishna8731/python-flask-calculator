# 🧮 Python Flask Calculator

A simple calculator web application built using Python and Flask. This project demonstrates how to build a web application with a Python backend and a frontend interface.

## ✨ Features

- Perform basic mathematical calculations.
- Use a web-based calculator interface.
- Process calculations using Python.
- Built with Flask for backend functionality.

## 🛠️ Technologies Used

- **Python** — application logic
- **Flask** — web framework
- **HTML** — page structure
- **CSS** — styling
- **JavaScript** — frontend interactions, if implemented

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Muralikrishna8731/python-flask-calculator.git
```

### 2. Open the project folder

```bash
cd python-flask-calculator
```

### 3. Install Flask

```bash
python -m pip install flask
```

### 4. Run the application

```bash
cd backend
python app.py
```

### 5. Open in your browser

Visit:

http://127.0.0.1:5000
